# Origem — documentos históricos

**Nada aqui se atualiza.**

Estes documentos registram o que foi decidido no início do projeto: por que ele existe, o que
se acreditava quando começou, quais decisões fundaram a arquitetura.

Quando `origem/` e `memory/` divergem, isso **não é inconsistência** — é a biografia do
produto, e é o que permite entender uma decisão estranha três anos depois.

## Arquivos

| Arquivo | Quando existe |
|---|---|
| `mvp-scope.md` | Só se o projeto entrou pela porta Descoberta |
| `fundacao.md` | Sempre |
| `prd.md` | Sempre |
| `base-tecnica.md` | Sempre |

> O **Domain Model não fica aqui** — ele vive em `memory/domain-model.md`, porque muda toda
> semana.

## Aviso obrigatório no topo de cada arquivo desta pasta

```
> **Documento histórico.** Registra o que foi decidido no início do projeto e NÃO reflete
> necessariamente o estado atual. Para o estado atual, ler `memory/produto.md` e
> `memory/estrutura.md`.
```

Sem esse aviso, o agente lê um PRD de um ano atrás como requisito vigente. É a forma mais
silenciosa de um harness envenenar a própria execução.
